Panduan Instalasi scrcpy (Device Mirroring)

Petak membutuhkan tool scrcpy di PATH untuk menampilkan mirroring layar perangkat Android tanpa lag.

Untuk macOS (Homebrew):
brew install scrcpy
Untuk Ubuntu / Debian Linux:
sudo apt update && sudo apt install scrcpy

Setelah instalasi selesai, klik tombol Pindai Ulang pada kartu Doctor di atas.
